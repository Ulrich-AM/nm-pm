# BS-006 - Blended Field Rendering and Repeated-Impact Variation

**Phase:** 3  
**Status:** Implemented  
**Milestone:** `blood-simulation-v0.4.0`  
**Date:** 2026-10-19

## Question

Can the persistent field render as one continuous blood mass instead of visibly layered translucent deposits, while still allowing repeated impacts with identical nominal settings to produce useful variation?

## Blended field rendering

The simulation field itself remains discrete and sharp.

Rendering samples a weighted 3 × 3 neighborhood around each visible field cell.

The resulting display amount is a blend of:

- the exact center-cell amount;
- a small Gaussian-like neighborhood average.

This creates a smoother perimeter without repeatedly modifying the stored simulation state.

## Opacity policy

Phase 2 allowed large alpha variation as amount accumulated.

That could make repeated deposits look like translucent images layered on top of one another.

Phase 3 instead treats occupied interior cells as nearly opaque.

Amount now primarily affects:

- thickness;
- darker interior tone;
- the extent of the smoothed perimeter.

Only low-coverage edge cells retain lower alpha.

Each rendered surface cell is still drawn once, so overlapping impacts merge through field amount rather than through multiple transparent sprites.

## Repeated-impact variation

The left-side seed control is now a **base seed**.

When `vary repeated impacts` is enabled, each impact derives a deterministic event seed from:

```text
base seed + impact serial
```

Small bounded variation is also applied to nominal direction, speed, incident angle, and volume.

The visible settings therefore remain the controlling values, but repeated impacts are not exact clones.

Turning the option off restores exact deterministic repetition for controlled tests.

## Success condition

BS-006 is successful if:

- overlapping deposits read as one continuous mass;
- repeated impacts do not create obvious transparent stacking bands;
- the field remains camera-independent;
- nominally identical impacts show recognizable variation;
- exact repeatability is still available when variation is disabled.

## Scope boundary

The neighborhood blend is a rendering approximation.

It does not replace physical spreading, which remains handled separately by the Phase 3 flow rules.
