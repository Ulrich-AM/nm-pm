# BS-001 - World and Surface Coordinate Foundation

**Phase:** 0  
**Status:** Implemented  
**Milestone:** `blood-simulation-v0.1.0`  
**Date:** 2026-10-19

## Question

Can a 2.5D orthographic side-room use a mathematically three-dimensional world and produce stable, representation-neutral surface impact data for floors, walls, and box-shaped obstacles?

## Camera correction

The first Phase 0 browser prototype interpreted the intended room as isometric.

That interpretation was rejected after visual clarification.

The corrected experiment uses an orthographic side-room / beat-em-up style camera:

- X remains screen-dominant left/right;
- Y represents front/back room depth;
- Z represents height;
- the camera has no perspective distance scaling;
- a downward viewing component keeps the floor and Y depth visible.

The original browser implementation is therefore treated as a superseded Phase 0 visualization, not the final camera policy.

## World model

```text
X = left/right
Y = front/back depth
Z = height
```

The room contains:

- floor;
- back and side boundaries;
- box-shaped obstacles;
- a player constrained to the ground plane.

## Surface model

Each planar surface stores:

- world-space origin;
- local U/V tangent axes;
- derived normal;
- finite dimensions;
- stable identifier and kind.

```text
P = O + uU + vV
```

## Probe protocol

A screen click creates an orthographic world-space ray.

The nearest finite surface intersection becomes a representation-neutral impact event containing:

- surface identity;
- world XYZ;
- local U/V;
- normalized local coordinates;
- normal;
- incoming direction;
- incident angle;
- speed;
- volume;
- droplet radius;
- deterministic seed.

Temporary red points are debug probes only.

## Native artifact

The canonical Phase 0 implementation is:

```text
phases/phase0/main.cpp
```

Pure Phase 0 geometry is kept in `phase0_math.hpp` and covered by `test_phase0.cpp`.

## Success condition

Later splat/field experiments must be able to consume the impact event without camera-space assumptions, special-case wall/floor coordinate logic, or perspective-dependent state.

## Known limitations

- planar rectangles only;
- no connected-surface transfer;
- no blood amount, wetness, spreading, dripping, pooling, or drying;
- simple player collision;
- static geometry only;
- the orthographic room camera is intentionally fixed for controlled testing.

These limitations are intentional for BS-001.
