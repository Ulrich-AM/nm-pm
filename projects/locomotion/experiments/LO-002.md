# LO-002 - Segment Mass, Center of Mass, and Support Geometry

**Phase:** 1  
**Status:** Implemented  
**Milestone:** `locomotion-v0.2.0`  
**Date:** 2026-10-20

## Question

Can the static LO-001 body support a deterministic whole-body mass model and useful support/stability measurements without applying any balancing correction?

## Segment model

LO-002 uses fourteen rigid body segments:

- head;
- trunk;
- left/right upper arm;
- left/right forearm;
- left/right hand;
- left/right thigh;
- left/right shank;
- left/right foot.

The segment mass fractions and longitudinal COM locations use the arithmetic mean of the female and male adjusted Zatsiorsky-Seluyanov parameters published by de Leva (1996).

This is a deliberate Phase 1 approximation. It avoids selecting one sex as the default reference subject while preserving a measured human-like mass distribution. The published rounded fractions sum to 0.99995, so whole-body COM explicitly divides by the observed total rather than assuming an exact sum of one.

## Segment COM

For a segment with proximal endpoint `P`, distal endpoint `D`, and longitudinal COM ratio `r`:

```text
C_segment = P + r(D - P)
```

Whole-body COM is the mass-weighted average:

```text
C_body = sum(m_i C_i) / sum(m_i)
```

The neutral LO-001 body produces a whole-body COM close to the sagittal midline and approximately 1.02 m above the ground.

## Support state

Phase 1 explicitly classifies support as:

- DOUBLE;
- LEFT;
- RIGHT;
- NONE.

The UI selects the state manually. Automatic contact detection belongs to a later moving-body experiment.

Each active foot contributes the rectangular LO-001 contact patch. The convex hull of all active patch corners becomes the support polygon.

## Static support margin

The vertical ground projection of whole-body COM is tested against the active support polygon.

The signed support margin is the shortest distance to the polygon edge:

- positive when the point is inside;
- negative when it is outside;
- unavailable when there is no support polygon.

This is a measurement only.

LO-002 never translates the pelvis or applies a force to improve the margin.

## Velocity-aware diagnostic

LO-002 also includes an extrapolated-COM diagnostic based on Hof's dynamic stability formulation.

For COM position `x`, horizontal COM velocity `v`, COM height `h`, and gravity `g`:

```text
omega0 = sqrt(g / h)
XCoM = x + v / omega0
```

The UI provides a few fixed velocity presets so the difference between static COM support and velocity-aware support can be inspected without simulating gait.

This diagnostic is not yet a controller target.

## Native harness

The Phase 1 application shows:

- the preserved neutral body;
- fourteen segment COM markers;
- whole-body COM and its ground projection;
- active foot outlines;
- the convex support polygon;
- COM velocity direction;
- XCoM;
- static and velocity-aware signed margins;
- DOUBLE / LEFT / RIGHT / NONE support presets;
- ZERO / SLOW FORWARD / FORWARD / RIGHT velocity presets.

The body remains motionless.

## Automated checks

LO-002 tests verify:

1. rounded segment mass fractions sum to approximately one;
2. whole-body COM is finite;
3. neutral COM remains centered;
4. neutral COM height is plausible for the reference rig;
5. paired thigh COM locations mirror;
6. double support contains the neutral COM projection;
7. left-only support excludes the centered COM;
8. right-only support excludes the centered COM;
9. no support produces no polygon;
10. zero velocity makes XCoM equal the COM projection;
11. forward velocity moves XCoM forward.

LO-001 tests remain in CTest and continue to run.

## Interpretation

LO-002 establishes the measurement layer required before any balance controller exists.

The experiment intentionally demonstrates that a centered static body is outside either single-foot support polygon. This is not treated as a bug. Human walking routinely enters states where static COM projection alone is not a sufficient stability description.

## Success condition

Later experiments must be able to consume:

- segment COMs;
- whole-body COM;
- COM velocity;
- support class;
- support polygon;
- static margin;
- XCoM;
- velocity-aware margin;

without those measurements modifying the pose.

## Intentional omissions

LO-002 does not implement:

- automatic contact detection;
- standing pose correction;
- IK;
- gait phase;
- stepping;
- physics forces;
- terrain;
- ragdoll behavior.

Those remain later research questions.
