# LO-007 - Continuous Locomotion State

**Study:** Anatomically Constrained Procedural Human Locomotion  
**Phase:** 6  
**Status:** Implemented and validated candidate for `locomotion-v0.7.0`  
**Date:** 2026-10-22

## Research question

Can the character retain continuous root motion, contact state, and coupled limb timing across support changes without treating each step as a resettable transaction?

LO-007 was introduced after the post-LO-006 flow audit showed that anatomically valid repeated steps could remain visibly march-like even when foot targets, joint limits, handoff continuity, pelvis/trunk coordination, and reference-informed arm geometry were all valid.

The purpose of LO-007 is therefore architectural. It does not claim to solve natural walking.

## Implemented state

Phase 6 introduces `locomotion6::ContinuousLocomotionState`.

Persistent state includes:

- simulation time and fixed tick count;
- root position;
- root linear velocity;
- root yaw and angular velocity;
- independent unwrapped left and right leg phase;
- bounded per-limb timing correction;
- persistent left and right arm response state;
- grounded or airborne foot contact;
- world-space planted ankle positions;
- temporary swing scaffold state;
- bounded contact-event history;
- support classification;
- previous-tick probes for continuity diagnostics;
- solved pose and LO-002 analysis.

A nominal gait-cycle boundary does not reconstruct this state.

## Fixed-step update

The pure locomotion state advances at:

`1 / 120 s`

The Phase 6 harness accumulates frame time and executes fixed simulation ticks. Persistent locomotion evolution is therefore independent of variable render-frame timing.

The update order is:

1. integrate root position and yaw from persistent velocities;
2. advance left and right unwrapped limb phases;
3. detect phase-readiness crossings that request release or touchdown;
4. update planted anchors or the temporary swing scaffold;
5. apply bounded timing correction at contact-transition events;
6. solve the constrained body pose;
7. update arm response and upper-limb geometry;
8. run support, anatomy, slip, and continuity diagnostics;
9. continue without a global gait reset.

## Root transport result

Root forward position is now integrated directly from persistent root velocity.

Support changes do not reconstruct or zero the root velocity.

The validated candidate reported:

- maximum root-velocity jump at contact: 0;
- maximum root-acceleration jump: 0;
- maximum root-angular-velocity jump: 0.

This is a steady-state architecture test. Desired speed is still chosen inside the validated LO-006 walking envelope. Start, stop, acceleration, and deceleration remain deferred to LO-014.

## Limb timing

Left and right legs retain independent unwrapped phases.

Wrapped phase is derived only when interpreting stance or swing readiness. Crossing an integer cycle boundary therefore does not reset limb identity or reconstruct controller state.

The two limb phases are softly coupled toward an alternating relationship. Timing disturbances can be introduced deliberately in the harness.

Contact-transition events apply a bounded phase correction and a decaying rate bias. This demonstrates that persistent timing can be corrected without a global controller reset.

### Important contact limitation

LO-007 does not yet perform physical foot collision detection.

Release and touchdown are still predicted from phase-readiness crossings in the flat-ground scaffold. The important result is that these contact-transition events now modify persistent state rather than ending a finite step transaction.

Physical contact handoff and impact remain later work, especially LO-010.

## Temporary swing scaffold

LO-007 deliberately keeps swing simple.

The free ankle moves through a deterministic smooth transfer with conservative clearance. The target is estimated from:

- the currently planted opposite ankle;
- the validated LO-006 step-length profile;
- continuing root position;
- a small root-velocity look-ahead.

This is scaffolding only. Functional swing initiation, shortening, mid-swing transport, terminal extension, and contact preparation remain LO-011.

## Flat-foot root/pelvis boundary

The largest remaining architectural limitation is the distinction between the persistent root and the currently displayed kinematic pelvis.

Root Y advances continuously from root velocity.

However, the flat-foot LO-003 leg solve still requires the displayed pelvis Y to remain near the midpoint of the current ankle targets. Phase 6 therefore substitutes the foot midpoint for the pose-solver pelvis Y while preserving the independent persistent root Y for continuing state, landing prediction, and diagnostics.

This prevents the existing 16 degree dorsiflexion guardrail from being weakened merely to make the new architecture pass.

It also means LO-007 does not yet prove that the visible body is dynamically transported over the planted stance foot.

That question is intentionally left to:

- LO-008 articulated stance foot;
- LO-009 dynamic stance / root transport.

## Reused foundations

LO-007 reuses:

- LO-001 anatomy, coordinate convention, segment lengths, joint envelopes, and foot markers;
- LO-002 COM/support analysis;
- LO-003 constrained two-leg solving and pelvis feasibility;
- Phase 5 velocity-profile helpers;
- Phase 5 two-link arm geometry.

It does not use the LO-004/005 step transaction, Phase 4 `ControllerState`, `sampleSequence()`, or Phase 5 `sampleCoordinated()` as the runtime source of locomotion.

## Upper-body boundary

The upper body remains intentionally conservative.

Persistent damped arm-response state survives support changes. Contralateral limb phase supplies a response preference, and the validated Phase 5 two-link arm geometry preserves segment lengths.

This is not the final reactive upper-body model. LO-013 will rebuild thorax, shoulders, arms, and head around actual root/stance dynamics.

## Validation

The accepted candidate contains 29 Phase 6 self-tests.

Windows CI built every preserved locomotion target and reported:

`7 / 7 CTest suites passed`

The candidate report additionally recorded approximately:

| Metric | Result |
|---|---:|
| Root velocity jump at contact | 0 |
| Root acceleration jump | 0 |
| Maximum per-tick phase correction | about 7.4e-6 |
| Maximum planted-foot slip | about 3e-17 m |
| Maximum segment-length error | about 4e-16 m |
| Deterministic replay | exact equality |

Tests cover:

- persistent root transport;
- left/right support transitions;
- unwrapped phase continuity;
- bounded timing correction;
- disturbance recovery;
- world-space planted contacts;
- support classification;
- LO-003 reachability;
- outer joint guardrails;
- exact segment lengths;
- fixed-step determinism;
- persistent arm state;
- indefinite locomotion without a step-count stop.

## Visual result

The Phase 6 harness walks indefinitely and no longer terminates after a requested integer number of steps.

Visual inspection did not show broken limbs or obvious planted-foot skating in the validated candidate.

The gait can still appear march-like.

That is not treated as an LO-007 failure because the articulated foot, stance transport, impact handoff, functional swing, pelvis flow, and reactive upper body have not yet been implemented.

## Result

LO-007 supports the architecture hypothesis.

The study can preserve root, limb timing, contact state, and arm response across support transitions without a `COMPLETE -> RESET -> next step` controller.

The result is narrower than natural locomotion:

`persistent locomotion state is viable, but flat-foot pose transport still prevents the visible body from fully following the persistent root.`

The next experiment is LO-008, which promotes heel, forefoot, and toe geometry into actual stance mechanics.
