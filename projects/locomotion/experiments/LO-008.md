# LO-008 - Articulated Stance Foot

**Study:** Anatomically Constrained Procedural Human Locomotion  
**Phase:** 7  
**Status:** Implemented candidate / visual QA checkpoint  
**Target release:** `locomotion-v0.8.0`  
**Date:** 2026-10-22

## Research question

Can articulated stance-foot contact reduce the flat-foot constraint observed in LO-007 while preserving persistent locomotion state, planted support, and anatomical guardrails?

LO-008 is a support-geometry experiment. It does not yet implement the full dynamic stance/root model.

## Implemented model

Phase 7 adds `locomotion7::ArticulatedLocomotionState` around the preserved LO-007 continuous state.

Each foot carries:

- AIRBORNE / HEEL / FLAT / FOREFOOT / TOE mode;
- current and target sagittal pitch;
- stance progress;
- heel-to-toe sole progress;
- planted heel, forefoot, and toe-tip positions;
- active ground pivot;
- foot-width support geometry.

The existing LO-001 heel, toe-base, toe-tip, ankle, and foot-width geometry remains the anatomical authority.

## Constraint formulation

The rocker is not a post-render foot rotation.

For a grounded foot:

1. the current support mode determines a ground pivot;
2. the pivot remains on the ground plane;
3. the rigid foot is pitched in the sagittal plane;
4. ankle position is derived from pivot + rotated foot geometry;
5. that ankle target is passed into the constrained LO-003 leg solve;
6. articulated heel / forefoot / toe markers are written from the solved ankle and the same foot pitch.

This means the rocker changes the actual kinematic constraint before solving the body.

## Support geometry

LO-002 support analysis is fed the currently active contact patch rather than an always-flat full-foot rectangle.

The support region changes through stance:

- HEEL: rear-foot support region;
- FLAT: full foot patch;
- FOREFOOT: support migrates forward and narrows;
- TOE: support narrows toward the toe / toe-base region;
- AIRBORNE: no support contribution.

Double support combines the active regions of both feet.

## Timing boundary

LO-008 still uses the persistent LO-007 limb phase to organize rocker progression.

Phase is used as contact-readiness / stance-progression timing, not as a complete authored joint animation.

Touchdown remains predicted rather than collision-driven. Physical impact and weight-transfer response remain LO-010.

## Root / pelvis experiment

LO-007 integrates persistent root Y continuously but keeps displayed pelvis Y close to the flat-foot ankle midpoint.

LO-008 allows the displayed pelvis to follow the persistent root by a conservative mode-dependent fraction while the articulated foot changes the ankle constraint.

The implementation includes a direct flat-foot versus articulated comparison at the same speed and duration.

If the articulated candidate can reduce the root/pelvis mismatch while remaining reachable and inside outer joint limits, the comparison records that improvement. If not, the mismatch remains an explicit boundary for LO-009 rather than being hidden by wider anatomical limits.

## Anatomy-preserving fallback

The existing LO-001 joint guardrails are unchanged.

If a requested articulated pose becomes invalid, Phase 7 first reduces root-follow and then reduces foot pitch toward flat. It does not widen ankle, knee, or hip limits.

This preserves LO-008 as a support-geometry experiment rather than changing anatomy to make the candidate pass.

## Validation

The Phase 7 implementation contains 29 self-tests.

The main-branch Windows CI after implementation built all Phase 0 through Phase 7 targets and passed:

`8 / 8 CTest suites`

The tests cover:

- articulated stance-state progression;
- heel / flat / forefoot / toe support regions;
- grounded active pivot;
- changing ankle constraint versus the LO-007 flat baseline;
- foot-pitch continuity;
- ankle-angle continuity;
- rocker-transition pose continuity;
- persistent root velocity and limb phase;
- exact segment lengths;
- reachability and outer joint limits;
- support-contact slip;
- active-marker ground validity;
- root/pelvis comparison;
- exact deterministic replay.

A validation typo in the support-polygon headline check was corrected before the v0.8.0 release trigger. The runtime geometry itself was unchanged.

## Harness

The Phase 7 harness provides:

- slow / ordinary / fast validated walk speeds;
- side, front, and three-quarter views;
- active foot mode;
- foot pitch;
- heel / forefoot / toe markers;
- active ground pivot;

- root/pelvis mismatch;
- ankle dorsiflexion;
- deterministic replay status.

This release is intended for visual inspection of the rocker, support migration, foot-ground continuity, and overall gait flow.

## Current limitation

LO-008 still does not provide full natural stance dynamics.

The articulated foot can change support constraints and reduce the flat-foot restriction, but:

- root transport is not yet generated by an inverted-pendulum, telescoping-leg, or compliant stance model;
- touchdown is scheduled rather than collision-driven;
- impact and weight transfer are not dynamic;
- swing remains the LO-007 temporary scaffold;
- pelvis/root flow is not yet optimized;
- upper-body motion remains conservative.

## Result status

LO-008 is accepted as a **testable articulated-foot checkpoint**, pending user visual evaluation.

The next major research step, if the visual QA does not expose a blocking LO-008 defect, is LO-009 dynamic stance / root transport.
