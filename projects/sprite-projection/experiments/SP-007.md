# SP-007 - Two-Link Pivot-Registered Articulated Sprite Composition

**Phase:** 6  
**Harness build:** 1.8.0  
**Status:** Implemented, native visual and quantitative results pending

## Question

Can independently reconstructed directional sprites represent two mathematically 3D rigid links connected by a moving hinge while preserving joint placement and useful silhouette accuracy?

## Rig

The first articulated subject is intentionally non-anatomical.

It consists of:

- an upper rectangular link;
- a lower rectangular link;
- one shared hinge;
- one mathematically exact root pose;
- one child orientation produced through matrix composition.

The hinge rotates around a fixed diagonal local XZ axis. This makes the lower part change both apparent 2D direction and camera depth as the joint moves.

## Sprite banks

The upper and lower links each receive an independent 40-view bank:

- 8 yaw samples;
- 5 pitch samples;
- 128 x 128 PNG captures;
- roll reconstructed in screen space.

Every capture is pivot-registered.

The link's top pivot is located at the center of the capture texture. Runtime composition places that texture center at the mathematically projected root or hinge position.

## Reconstruction methods

SP-007 reuses the exact shared implementations of:

- NEAR
- STRETCH
- SHEAR
- AFFINE
- DUAL
- GRID4

No articulation-specific copy of these algorithms exists.

## Depth ordering

The two complete part sprites are sorted by their 3D center Z value.

The farther link is drawn first.

This is a deliberately simple first depth policy and is expected to fail in more complicated overlap conditions.

## Interactive lab

The Phase 6 executable exposes:

- root yaw;
- root pitch;
- root roll;
- hinge angle;
- animated root rotation and hinge swing;
- endpoint trace;
- pivot markers;
- all six reconstruction methods;
- true 3D reference and multi-sprite approximation side by side.

## E6 protocol

E6 evaluates the combined articulated silhouette over:

- yaw: 0 through 330 degrees in 30-degree increments;
- pitch: -30, 0, +30 degrees;
- hinge: -60, -30, 0, +30, +60 degrees;
- 180 articulated poses;
- all six reconstruction methods.

Metrics:

- silhouette IoU;
- symmetric boundary error;
- centroid displacement.

The export also records which link center is closer to the camera for each pose.

Outputs:

- `results/phase6/E6_two_link_metrics.csv`
- `results/phase6/E6_two_link_summary.csv`

## Scope limitation

Joint position is not treated as a free reconstruction variable in SP-007.

The sprites are explicitly pivot-registered and placed at the true projected pivot positions. Therefore this experiment asks whether the independently reconstructed link appearances compose correctly around a known joint, not whether an image-space method can infer the joint.

Later articulated experiments can intentionally relax this assumption or use more complex per-sprite pivot metadata.

## Next articulation step

If SP-007 is usable, the next controlled experiment should extend the same system to a three-link chain. That introduces two joints, more depth-order transitions, and more opportunities for adjacent sprites to overlap incorrectly before any humanoid anatomy is introduced.
